# Working with the YNAB SDLC guide

Follow the research repository instructions and preserve the active handoff in
PROGRESS.md. Jira owns requirements and owner approvals. Keep actual site URLs,
attachment/comment IDs, credentials and financial data out of this public guide.

When executing this guide, completion requires independent Jira read-back after
any Done transition: status Done in category `done`, resolution Done with an ID,
and a populated resolutiondate for successfully delivered work. Do not report
closure based only on a successful transition response, status badge or merge.
Missing fields, API failure or a mismatch leave closure unverified.

Follow the completion and reopening checks, paginated consistency audit and
bounded correction procedure in `02-codex-workflow.md` section 2.6. At resume,
check the audit before relying on earlier Done claims. Preserve approved issue
fields. Record live verification in Jira evidence and generic outcomes in
PROGRESS.md. This audit does not grant authority to close unrelated work.

Application changes still require feature branches/PRs and a separate owner
merge decision. Do not overwrite the application's AGENTS.md with the template.
